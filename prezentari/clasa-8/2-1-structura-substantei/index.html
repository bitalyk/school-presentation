2.1 · Fenomene termice

Starea termică. Temperatura

Starea termică a unui corp fizic exprimă starea lui internă și este determinată de mărimea fizică numită temperatură.

Temperatura este legată de mișcarea particulelor din care este alcătuit corpul: cu cât particulele se mișcă mai repede, cu atât temperatura corpului este mai mare.

2.1 · Fenomene termice

Echilibrul termic și procesul termic

Mărimea fizică ce caracterizează starea de încălzire a unui corp sau a unui sistem de corpuri fizice aflate în echilibru termic este numită temperatură. Trecerea unui corp fizic dintr-o stare de echilibru termic în alta se numește proces termic.

2.1 · Fenomene termice

Măsurarea temperaturii. Scări termometrice

Există mai multe scări de temperatură:

Celsius (°C)Kelvin (K)Fahrenheit (°F)Réaumur (°R)

  • Celsius — cea mai folosită în viața de zi cu zi: 0 °C — topirea gheții, 100 °C — fierberea apei.
  • Kelvin — scara absolută: 0 K este zero absolut, când mișcarea termică a moleculelor încetează. 1 K = 1 °C.
În SI temperatura absolută T se măsoară în kelvini: [T]SI = K. Temperatura în grade Celsius se notează cu t.
T(K) = t(°C) + 273,15 t(°C) = T(K) − 273,15 · exemplu: 20 °C = 293,15 K

2.1 · Fenomene termice

Energia internă

Starea termică a corpului fizic este caracterizată de temperatura acestuia, care este măsura energiei cinetice medii a moleculelor din care-i constituit.

Energia de mișcare și de interacțiune a particulelor din care constă corpul fizic se numește energia internă a corpului.
Concluzie:
  • Energia internă a unui corp, ca și temperatura, este o mărime fizică ce caracterizează starea termică a corpului.
  • Variația energiei interne a unui corp depinde numai de energia lui în starea inițială (U1) și cea finală (U2).
energie de mișcare energie de interacțiune
Energia internă se notează cu litera U.   [U]SI = J

2.1 · Fenomene termice

Transferul de căldură. Cantitatea de căldură

Procesul variației energiei interne a unui corp cauzat de primirea sau cedarea căldurii se numește transfer de căldură sau transmitere de căldură. Mărimea fizică ce caracterizează variația energiei interne a corpului în procesul transferului de căldură se numește cantitate de căldură.

Cantitatea de căldură se notează cu litera Q. Unitatea de măsură în SI este joule (J):  [Q]SI = J

Energia internă a unui corp crește datorită cantității de căldură primite de la alt corp:

U2 − U1 = Q
